**LINE FOLLOWING ROBOT**
This project is a compact and efficient line following robot built using an Arduino Nano, a TB66FNG motor driver, and a 7-channel IR sensor array. The robot is designed to detect and follow a dark line on a light surface by continuously reading reflectance data from the sensor array and adjusting motor speeds accordingly. The 7-sensor configuration provides precise position feedback, allowing smoother and more accurate turns compared to basic 3-sensor setups. The TB66FNG driver enables reliable control of two DC motors, ensuring stable performance even during sharp turns or speed changes. This robot is ideal for learning real-time embedded control, sensor calibration, and basic robotics algorithms, and can be extended with PID control for enhanced path tracking.
